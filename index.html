Sobre o projeto

        

          

            

              API na Prática é um Recurso Educacional Aberto criado para ensinar
              noções fundamentais de Programação Web Back-End a pessoas sem formação técnica superior.
              Usamos linguagem simples, exemplos do dia a dia e uma construção incremental.
            

            

              O produto que atravessa todas as aulas é uma API REST para uma biblioteca comunitária:
              livros, cadastros e consultas são coisas fáceis de imaginar, o que deixa o código em primeiro plano.
            

          


          

            

              
Para quem

              
Jovens e adultos a partir de 15 anos, sem formação técnica superior.

            

            

              
O que você encontra

              
Seis módulos com texto curto, glossário, videoaulas de 5 a 7 minutos, exercícios e o código de cada etapa.

            

            

              
Acessível

              
Vídeos com legendas em português e transcrição na mesma página, site navegável por teclado e código em texto selecionável.

            

            

              
Aberto

              
Conteúdos em CC BY 4.0 e código em licença MIT. Você pode usar, adaptar e compartilhar.

Os próximos módulos

        

          

            Módulo 2: Rotas como endereçosEm breve
            
URL, parâmetros, query strings e códigos HTTP. Você cria GET /livros e GET /livros/:id.

          

          

            Módulo 3: Cadastro de livrosEm breve
            
JSON, POST, PUT, DELETE e CRUD. Você cadastra, altera e exclui livros, ainda em memória.

          

          

            Módulo 4: Dados que permanecemEm breve
            
Persistência, tabelas e chaves. Você conecta a API ao SQLite e reinicia o servidor sem perder os livros.

          

          

            Módulo 5: Entradas segurasEm breve
            
Middleware, validação e erros. Você valida campos e padroniza as mensagens de erro.

          

          

            Módulo 6: Qualidade e publicaçãoEm breve
            
Testes automatizados, documentação e uso responsável. Você testa as rotas e documenta a API.
